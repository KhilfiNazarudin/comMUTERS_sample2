# comMUTERS

A 2D platformer beat-em-up game built by nontoxicworkplace at DigiPen (AY2025/T2).

This was made as an academic project for DigiPen's AY2025/T2 term.

## Download & Play

1. Click the green **Code** button on this repo, then select **Download ZIP**.
   - Total size is ~13.7MB, so it may take a moment to download.
2. Once downloaded, extract the ZIP file.
3. Open the extracted folder and navigate to `Release-x64`.
4. Run `comMUTERS.exe`.
5. Windows Defender may show a warning that this is an unrecognized app. Click **More info**, then **Run anyway** to launch the installer and play.

## Controls

Controls are displayed in the top-right of the screen after Digipen and the game's splash screen.

## Tech Stack

- **Language:** C++
- **Framework:** DigiPen's Alpha Engine
- **Audio:** FMOD

## Level Data

Level data is saved locally at `Release-x64/Assets/SAVES/Level_1save.txt`.

## Assets

Game assets are located in `Release-x64/Assets`. Assets are sourced primarily from [Kenney Assets](https://kenney.nl/) and DigiPen.
